Connect to the main Mac

Connect the Macs with a Thunderbolt cable, then open Workspace → Nodes on main and start connections. Copy its numeric Thunderbolt Bridge address, including the port. Tasks and results use the cable while each Mac uses its own internet connection. Use Check connection before pairing. Node traffic does not fall back to Wi-Fi. 127.0.0.1 works only if both apps run on this same Mac.

Local Bilibili sign-in · optional

The cookie stays in this node's memory and is never sent to the main Mac. If blank, fetching uses this Mac's environment credential or local cookie file, if available.

HTTP node connections bind to Thunderbolt Bridge. Pairing credentials stay in memory. Restarting either app requires pairing again. The cable does not share internet access; keep Internet Sharing off to use separate internet connections.

A pairing code admits one node and expires after five minutes. A connected node can run many collections without another code.
